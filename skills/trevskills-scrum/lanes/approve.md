# Approve

1. Run `B set $ID stage=approve`. Spawn `scrum-approver` and wait for it. Prompt: the 5 lines plus `Decide this job. Write decision.md.`
   - **Model:** run `B route-check $ID`, adding `--clean-start` only when this session knows the round was not started by the Merge **Conflicts** step. Pass Agent override `model: "sonnet"` to `scrum-approver` when its `approver_sonnet` is `true`. Otherwise, when the Merge schema guard regex `(^|/)prisma/(schema\.prisma|migrations/)|\.sql$` matches no file in `git -C "$WT" diff --name-only "$BASE"...HEAD`, pipe **Review** step 2's Jev gate diff line plus `grep -m1 '^# ' "$F/jobs/$ID/spec.md"` to `python3 ~/.claude/skills/trevskills-scrum/jev-gate.py approver $F/jobs/$ID` (Bash timeout 90000). Output `sonnet` passes `model: "sonnet"`. When the schema guard matches, make no Jev call. In every other case (even when you can't tell) omit the override so Opus runs.
2. Copy `decision.md` into `round-$N/decision.md`; that's how the approver later sees whether REWORK has already been used. Run `B sync $ID` and read `decision`.
3. **Manual checks and follow-ups.** First, when `decision.md` has a non-empty `## Manual checks` section that is not just `- none`, run `B manual-add "<item> (from $ID)" ...`, one argument per bullet. It appends them to `$F/manual-checks.md`, never to the backlog. Do this whether or not `## Follow-ups` is empty; if `manual-add` exits non-zero, name it in the final report only.
   Then, when its `## Follow-ups` section is missing, empty or just `- none`, spawn nothing, run neither `backlog-spec` nor `backlog-add`, and go to step 4. Otherwise pre-write a spec per follow-up:
   - If the board's `specwriter` is a recorded agent id, use SendMessage to it, the same way **Resuming the builder** does. Spawn a fresh `scrum-spec-writer` (see **Routing**) instead when `specwriter` is missing, empty or not an agent id, or when SendMessage fails because the agent no longer exists. The message or prompt is:
     ```
     JOB_DIR=$F/jobs/$ID
     BACKLOG=$F/backlog.md
     PROJECT=$F/project.md
     Run follow-up mode: pre-write a spec for each Follow-ups bullet in decision.md.
     ```
   - Wait for it, then run `B backlog-spec $ID`; when it succeeds, run `B rank-backlog` once. Name any `skipped` files or `rank-backlog` failure in the final report only; neither stops the job.
   - **Fallback:** if the spec writer fails, leaves no `$F/jobs/$ID/followups/*.md`, or `B backlog-spec $ID` exits non-zero, skip each bullet the repository shows is already done (name it in the final report), run the **Dupe check** and **Rank** (3c, `jev-gate.py dupe`) on each other bullet, then `B backlog-add "<item> (from $ID)" ...`, one argument per bullet.

   This step never blocks or sets needs-human; go on to step 4.
4. Route:
   - `APPROVE`: go to **Merge**.
   - `REWORK` and sync's `"reworks"` is greater than 1: the approver broke the once-only rule. Run `B ask $ID "approver requested second rework; see decision.md." --kind round-limit --a "Merge anyway=approve $ID" --b "Send back with a note=rework $ID \"apply the rework decision.md asks for\"" --c "Remove this job=abort $ID --cascade" --recommend <key> '<why>'` and stop.
   - `REWORK` (first time): run `B set $ID limit=$((N+1)) stage=build`. Resume the builder with `The approver requested rework: read JOB_DIR/decision.md (Rulings marked fix-now), fix, commit, update build.md.` Then go to **Check gate**.
   - `ESCALATE` or `INVALID`: the question is the second line of `decision.md`. If it starts `Hard stop: blocked`, run `B ask $ID '<second line of decision.md>' --kind blocked --a "Send back with a note=rework $ID \"make the most reasonable call on the blocker in decision.md and record it as a Ruling in build.md\"" --b "Remove this job=abort $ID --cascade" --recommend <key> '<why>'`. If it starts `Hard stop: render`, run `B ask $ID '<second line of decision.md>' --kind render --a "Merge anyway=approve $ID" --b "Send back with a note=rework $ID \"render the changed page and see the change, or write Rendered: n/a when nothing on screen changed\"" --c "Remove this job=abort $ID --cascade" --recommend <key> '<why>'`. For any other second line, run `B ask $ID '<second line of decision.md>' --a "Merge anyway=approve $ID" --b "Remove this job=abort $ID --cascade" --recommend <key> '<why>'`. For INVALID, run `B ask $ID "approver output unreadable." --a "Merge anyway=approve $ID" --b "Send back with a note=rework $ID \"re-check the change against spec.md and fix what is missing\"" --c "Remove this job=abort $ID --cascade" --recommend <key> '<why>'`. Report and stop.
